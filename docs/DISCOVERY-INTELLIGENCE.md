# OLFACTUS Discovery Intelligence Engine

Model version: `DE-1.0.0`

The engine ranks unowned fragrances using:
- collection fit
- DNA expansion
- missing-role contribution
- seasonal value
- originality / redundancy
- performance
- intelligence data confidence
- strategic gap alignment

Outputs include:
- primary recommendation
- ranked recommendations
- explainable signals
- projected Collection Health
- blind-buy risk
- opportunity feed
- discovery roadmap
