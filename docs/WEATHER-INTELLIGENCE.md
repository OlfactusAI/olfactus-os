# OLFACTUS Weather Intelligence

Version: v1.1.0

Uses browser geolocation or a manually selected city to retrieve temperature,
apparent temperature, humidity, precipitation probability, wind, UV, and
weather condition data from Open-Meteo.

The application falls back to season-based context when location permission is
denied, weather is disabled, or the service is unavailable.

Local storage:
- olfactus.weather.preferences.v1
- olfactus.weather.cache.v1
