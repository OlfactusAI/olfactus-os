# OLFACTUS OS v2.5.0-alpha.1 — Intelligence Memory Core

## Unified memory schema

Every event has a stable ID, timestamp, event type, source, optional entity,
confidence, metadata, and schema version.

## Recorded in this release

- workspace navigation
- collection additions and removals
- wear records
- favorite changes
- Analyst searches, comparisons, recommendations, and confirmed actions

## Query and learning APIs

The query layer calculates event totals, wear leadership, view leadership, and
recommendation acceptance.

The learning layer requires repeated evidence before creating an insight.

## Collector DNA

Initial dynamic traits include Explorer, Curator, Minimalist, Maximalist,
Daily Wearer, Signature Loyalist, and Safe Buyer.

## Memory workspace

`/memory` provides Collector DNA, learned insights, an event timeline, export,
import, and reset controls.
