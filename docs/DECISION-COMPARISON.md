# OLFACTUS Decision Comparison

Model: `DC-1.0.0`

Compares two unowned candidate fragrances using the Decision Lab.

Comparison categories:
- purchase score
- collection fit
- DNA expansion
- role value
- season value
- performance
- value efficiency
- long-term ownership
- overlap risk
- regret risk

The engine returns one winner, a comparison confidence score, winner reasons,
and areas where the runner-up still performs better.
