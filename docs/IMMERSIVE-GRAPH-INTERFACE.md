# OLFACTUS Immersive Graph Interface

Version: `v1.5.0b`

Adds:
- lightweight force-directed motion
- draggable nodes
- canvas pan
- extended zoom
- full-screen explorer
- node-type filters
- owned-only filter
- relationship-strength filter
- animated edge particles
- comparison-node selection
- two-fragrance relationship analysis
- selection history
- graph minimap
- responsive large-catalog limits

Interactions:
- click: select node
- drag node: reposition
- drag empty canvas: pan
- double-click fragrance: select comparison node
