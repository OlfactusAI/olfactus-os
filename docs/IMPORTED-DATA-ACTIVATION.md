# OLFACTUS v2.0.0c-4 — Imported Data Activation

The active catalog runtime merges bundled and browser-imported fragrances.

It exposes the complete catalog, bundled and imported subsets, imported IDs,
readiness levels, hydration state, and a manual refresh function. Import
commits dispatch a browser event so active pages update without restarting.

Activated areas include Collection Provider, Explorer, Deal Lab, Brand
Intelligence, Perfumer Intelligence, Knowledge Graph, and Lineage.

Imported records are classified as Ready, Partial, Search only, or Blocked.
Search-only records remain discoverable but are not presented as authoritative
advanced-scoring data.
