# OLFACTUS OS v2.3.0-alpha.2 — Live Intelligence Integration

## Live dashboard

Dashboard 2.0 now derives its personal intelligence from the current
collection and active catalog. Fixed demonstration values have been
removed.

The live selector calculates:

- collection size
- Collection Health
- role coverage
- seasonal balance
- DNA diversity
- redundancy
- rotation balance
- dominant family
- neglected bottle
- recommended wear

## Honest missing-evidence states

When market, weather, timeline, or simulator evidence is unavailable,
the dashboard says so. It does not present sample values as personal
intelligence.

## Automatic events

Live synchronization generates deduplicated events for:

- Collection Health changes
- neglected rotation thresholds
- ten-bottle collection milestones

## Dashboard preferences

Users can show or hide modules, switch between compact and expanded
layouts, and reset the dashboard.
