# OLFACTUS v2.0.0c-2 — Global Search Interface

Adds a persistent Universal Search control to the OLFACTUS application shell.

## Access

- click the top-bar search control
- press Command-K on macOS
- press Control-K on Windows or Linux
- press Escape to close

## Interface

- instant multi-entity results
- fragrances, brands, perfumers, notes, accords, ingredients, and lines
- entity filters
- grouped result sections
- match explanations
- imported-data badges
- Arrow Up and Arrow Down navigation
- Enter to open the active result

## History

Browser-local persistence stores:

- recent search queries
- recently opened entities
- clear-history control

## Routing

Results route directly to Explorer, Brand Intelligence, Perfumer Intelligence,
Database, or Lineage as appropriate.

## Empty states

The search interface provides suggested searches before typing and links to
the Import Workspace when a requested entity is not available.
