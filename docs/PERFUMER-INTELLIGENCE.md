# OLFACTUS v1.8.1 — Perfumer Intelligence

Model: `PIO-1.0.0`

Adds:

- `/perfumers`
- curated perfumer attribution registry
- creator directory
- perfumer search and sorting
- signature DNA
- portfolio performance and data-quality metrics
- strongest families and recurring creative themes
- collection coverage
- most artistic, versatile, and influential work
- personalized next-work recommendation
- brand network
- comparison mode for up to three perfumers
- Explorer, Deal Lab, and Knowledge Graph links

## Attribution integrity

OLFACTUS does not assign speculative creator credits. Records without a
verified attribution in the current curated dataset remain explicitly
undisclosed.

Structured recurring-note and recurring-accord analysis will expand as verified
material metadata is added to the global database.
