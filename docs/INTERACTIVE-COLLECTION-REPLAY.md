# OLFACTUS v1.7.0b — Interactive Collection Replay

Adds:
- `/evolution` workspace
- manual snapshot capture
- automatic baseline and significant-change snapshots
- replay slider
- automatic playback
- selectable comparison baseline
- Collection Health, Diversity, Rotation, and Role Coverage replay
- eight-dimension DNA replay
- before-and-after snapshot cards
- dominant brand and family shifts
- evolution milestones
- OLFACTUS Evolution Analyst
- demo replay baseline for new installations

Automatic snapshots are captured when:
- the owned fragrance set changes
- five or more additional wears have accumulated since the last snapshot
