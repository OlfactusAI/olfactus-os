# OLFACTUS v2.0.0c-3 — Universal Entity Dossiers

## Route-aware selection

- `/brands?brand=...` opens the requested brand dossier
- `/perfumers?perfumer=...` opens the requested creator dossier
- `/database?note=...` opens a note intelligence dossier
- `/database?accord=...` opens an accord intelligence dossier
- `/database?ingredient=...` supports ingredient intelligence
- `/lineage?line=...` selects the exact fragrance line
- `/lineage?fragrance=...` continues to resolve a fragrance's line

## Note dossiers

- classification and naturality
- usage counts
- leading brands
- related accords
- representative fragrances
- average longevity

## Accord dossiers

- definition
- related notes
- fragrance families
- representative fragrances
- average projection

## Ingredient dossiers

- origin
- production methods
- odor profile
- volatility
- related notes
- confidence metadata

This phase turns Universal Search routes into meaningful intelligence views.
