# OLFACTUS v2.1.0-alpha.1 — Intelligence Layer 3

Single integrated release containing:

- Dynamic Knowledge Graph Runtime
- AI Collector Assistant on Today
- expanded live Timeline event model and replay engine
- functional Neural Collection Simulator at `/simulator`
- scalable Database 3.0 repository architecture with pagination, batch commits, provenance, and capacity planning

The database scaling layer supports growth toward 5,000–50,000 records, but this package does not invent unverified fragrance records. Data expansion remains source-driven through imports.
