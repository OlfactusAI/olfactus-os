# OLFACTUS v1.9.0b — Lineage Workspace

Adds:

- `/lineage`
- searchable fragrance-line directory
- family overview cards
- visual release chronology
- parent and flanker tree presentation
- DNA inheritance bars
- evolution scoring
- performance comparison table
- longevity and projection deltas
- concentration progression cards
- active and discontinued branch summaries
- NEXUS workspace integration

The workspace displays complete lines found through curated or conservative
inferred lineage data. When the catalog contains only one release from a line,
that fragrance remains an orphan until related flankers are imported.

The next phase, v1.9.0c, will add collection-aware Upgrade Intelligence,
complement-versus-replacement analysis, and family redundancy detection.
