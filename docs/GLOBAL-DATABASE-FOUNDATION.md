# OLFACTUS v1.8.0a — Global Database Foundation

Schema: `GFD-1.0.0`

## Normalized entities

- fragrances
- brands
- perfumers
- notes
- accords
- countries and regions
- concentrations
- asset references
- ratings
- relationships and flankers
- source references

## Foundation capabilities

- canonical IDs and slugs
- alias normalization
- data-quality scoring
- database validation
- duplicate-fragrance detection
- searchable index generation
- query and filter API
- structured row import
- rejected-row reporting

## Current scope

This release normalizes the existing curated catalog. It does not yet connect
to a live external fragrance dataset or retailer feed.

## Next milestone

v1.8.0b will add Advanced Search and the full Fragrance Explorer.
