# OLFACTUS OS v4.3.0-alpha.1 — Global Intelligence Network Foundation

GIN-1.0.0 is the service-first global fragrance-world graph.

It adds typed entities, weighted relationships, reusable graph queries,
shortest-path traversal, graph metrics, Unified Intelligence API access,
Analyst graph evidence, and System diagnostics.

The first alpha derives catalog-backed and calculated relationships. Rich
curated company ownership, clone lineages, inspiration chains, collections,
and expanded perfumer/ingredient data are reserved for v4.3.1.

The existing /graph visualization is intentionally preserved. v4.3.0 installs
the new global graph beneath the working UI first.
