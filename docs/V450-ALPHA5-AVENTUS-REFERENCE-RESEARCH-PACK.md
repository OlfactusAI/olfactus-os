## Sources

The Aventus pack uses:

- The House of Creed official Aventus product page
- Parfumo
- Fragrantica
- Basenotes

The official source is treated as primary for current product identity and
current official note presentation. Community databases are used for aggregate
wear perception, ratings, similarity context, and source comparison.

## Research included

- 2010 release evidence

- current official character language
- community accord classification

- current Fragrantica rating
- performance variability caution
- major Aventus similarity lineage

- current-official versus legacy/community note-list disagreement
- Creed batch-process statement

## Integrity rule

The pack contains **zero OLFACTUS calibration scores**.

Reviewer A and Reviewer B see the same source evidence but must independently
choose score, confidence, rationale, and evidence interpretation.

The authoring UI displays the imported evidence beside each relevant calibration
section without copying evidence into claims or populating numeric values.
