# OLFACTUS OS v4.4.6-alpha.3 — Reference Intelligence Laboratory: Calibration Workspace

Milestone 2 of the Reference Intelligence Laboratory.

## Route

`/reference-lab`

## Capabilities

- select one of the first 25 Reference Phase I targets
- edit calibration scores
- record confidence independently from score
- write a calibration rationale
- record evidence observations
- attach an optional supporting source URL
- see section-by-section completion
- see overall scoring/evidence/confidence readiness
- save drafts locally
- submit only complete drafts for review
- materialize explicit scores into Reference Lab claims/evidence
- enforce read-only behavior for locked workspaces

## Deliberately excluded

This release does not:

- calculate consensus
- resolve reviewer conflicts
- issue Gold Standard certificates
- auto-promote a fragrance into NRE
- generate calibration scores automatically

That keeps calibration authoring separate from review and certification.

## Phase I targets

The workspace contains 25 benchmark targets spanning designer, niche, heritage,
fresh, woody, amber, aromatic, gourmand, oud, green, mineral, and high/low
performance styles.

The target list contains identities only. No calibration values are pre-filled.
