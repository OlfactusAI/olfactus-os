# OLFACTUS OS v4.4.8-alpha.1 — First Live Gold Standard Reference: Creed Aventus

This milestone proves the complete governed reference pipeline end-to-end with
Creed Aventus.

## Important integrity rule

This release does **not** hard-code or invent Aventus calibration scores.

Aventus can only become live if the repository already contains a real chain:

1. reviewed Aventus consensus
2. Gold Standard certificate
3. Reference Registry record
4. complete production fingerprint bundle
5. approved production promotion package
6. production activation package

If any step is missing, activation remains blocked and the diagnostic route
shows the missing stage.

## Route

`/reference-live/aventus`

## Runtime proof

Once active, the route verifies that the runtime reference contains:

- certificate identity
- certificate hash
- source consensus identity
- all ten required production fingerprint kinds

The runtime entity therefore remains traceable back to the exact Gold Standard
consensus that generated it.

## Why no seed scores are included

The Reference Intelligence Laboratory was deliberately designed to prevent
fabricated intelligence from entering production. Shipping synthetic Aventus
scores merely to make the first live reference appear complete would bypass the
governance system the previous releases established.

This milestone instead proves the real pipeline and makes any missing evidence,
review, consensus, certification, fingerprint, or activation stage explicit.
