# OLFACTUS OS v4.4.0-alpha.1 — Neural Recommendation Engine 2.0 Foundation

This release introduces NRE-2.0.0, a modular explainable recommendation
pipeline.

Core factors:
- preference fit
- role-gap coverage
- collection overlap
- weather fit
- seasonal fit
- blind-buy risk
- budget fit

Every ranked candidate receives:
- score
- confidence
- factor-by-factor recommendation trace
- advantages
- disadvantages
- net trade-off assessment
- opportunity-cost comparison

The release is intentionally service-first. UI expansion follows after the
reasoning engine is stable.
