# OLFACTUS OS v2.4.0-alpha.1 — Proactive Analyst

## First reliable capabilities

1. Explain Collection Health
2. Recommend from the owned collection
3. Find the three most neglected bottles
4. Compare active fragrance entities
5. Preview and confirm a wear-record action

## Commands

- `/explain collection-health`
- `/recommend tonight`
- `/find neglected`
- `/compare Ganymede vs Reflection Man`
- `/wear Imagination`

## Guardrails

- unresolved fragrance names are never invented
- recommendations are limited to the owned collection
- collection mutations require explicit confirmation
- every answer labels verified, calculated, estimated, or unavailable
  evidence
- confirmed wears use the existing collection provider, timeline, and
  recovery-compatible data flow
- Analyst activity is stored in a local ledger for later diagnostics

## Global interface

The existing OLFACTUS Analyst control has been upgraded into a
conversational panel. It is workspace-aware and can be opened with
Command/Control + Shift + K.
