# OLFACTUS OS v2.3.0-alpha.1 — Intelligence Everywhere

## Included systems

- Live Intelligence Overlay
- Context-Aware Panels
- Explain Every Score
- Recommendation Trace
- Intelligence Event Engine
- Behavioral Memory Engine
- Mission Control Dashboard 2.0
- Intelligence Everywhere diagnostics

## Explainability

Every score can now be represented by a shared contract containing:

- score
- confidence
- positive contributors
- negative contributors
- weighted evidence
- source explanations

## Recommendation trace

Recommendation decisions can expose a six-step path through weather,
collection state, role gaps, budget, DNA diversity, and performance.

## Intelligence events

The event ledger stores milestones and state changes such as collection-health
movement, rotation streaks, market alerts, wear streaks, and DNA milestones.

## Memory engine

The memory layer does not create insights from one observation. Memory
inference requires repeated evidence and records confidence, evidence count,
first observation, and last observation.

## Dashboard 2.0

The Today workspace receives a mission-control section that combines score
explanations, context intelligence, recommendation traces, event activity, and
learned behavioral patterns.
