# OLFACTUS v1.9.0a — Lineage Core

Engine: `LIE-1.0.0`

## Core model

- fragrance lines
- original releases
- parent and child flankers
- generations and release order
- concentration identifiers
- release status
- predecessors and successors
- limited editions and reformulations
- clone relationships
- inspiration relationships
- confidence and data provenance

## Intelligence

- DNA inheritance percentage
- DNA dimension deltas
- evolution score
- originality score
- longevity, projection, and sillage deltas
- chronological line construction
- active and discontinued branches
- graph-ready lineage edges
- orphan detection
- conservative line inference

## Data strategy

Curated lineage records override inferred records when their confidence is
equal or higher. The current catalog contains mostly one fragrance per line,
so the bundled curated registry is intentionally empty until verified line
members are imported.

The next phase, v1.9.0b, will expose this engine through the `/lineage`
workspace with family trees, chronology, DNA evolution, and performance
visualizations.
