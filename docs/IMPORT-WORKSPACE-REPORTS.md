# OLFACTUS v2.0.0b-4 — Import Workspace & Reports

Adds `/import` with JSON/CSV upload, pasted payloads, match previews,
classification filters, per-record decisions, conflict resolution, commit
confirmation, browser-local persistence, and downloadable JSON reports.

Committed records are stored in browser localStorage. They do not rewrite the
project source files. This completes the v2.0.0b Import Engine series.
