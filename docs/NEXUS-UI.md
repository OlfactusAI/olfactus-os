# OLFACTUS v1.8.0d — NEXUS UI

## Navigation

- fixed OLFACTUS sidebar header
- independently scrollable workspace region
- scroll position persistence
- grouped Dashboard, Knowledge, Analytics, and Account sections
- collapsible sections
- workspace search
- favorites
- recent workspaces
- locally calculated most-used workspaces
- active-route highlighting
- mobile workspace drawer

## Global experience

- Command Palette using Command-K or Control-K
- global workspace index
- breadcrumb bar
- page transition animation
- reusable skeleton loader
- reduced-motion support

## Storage keys

- `olfactus.navigation.favorites.v1`
- `olfactus.navigation.recents.v1`
- `olfactus.navigation.analytics.v1`
- `olfactus.navigation.scroll.v1`

Navigation data remains local to the browser.
