# OLFACTUS v1.8.0c-1 — Brand Intelligence

Model: `BIO-1.0.0`

Adds:
- `/brands`
- brand directory
- brand search and sorting
- Brand DNA
- average performance and data quality
- collection coverage
- signature fragrance ranking
- next-purchase recommendation
- market positioning
- release timeline
- comparison mode for up to three brands
- Explorer, Deal Lab, and Knowledge Graph links

Current intelligence is calculated from the normalized curated catalog. Brand
metadata such as founding year and country will become richer as the global
database expands.
